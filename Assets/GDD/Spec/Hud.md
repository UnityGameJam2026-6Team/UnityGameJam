# B5 HUD 스펙

- 상태: 확정
- 근거: 게임플레이 기획 §2·§8·§9, B 레인 실행 계획 B5, Undecided U4·U21, DesignIssue D5
- 범위: Facility 플레이 중 상시 HUD와 플레이어 작업 게이지. 배정·제안은 B6, 마감 연출과 결과는 B7에서 연결한다.
- 네임스페이스: `UnityGameJam.UI`

## 목적

플레이어는 남은 시간과 시설 전체 점수를 보며 다음 행동을 고른다. 개별 방의 청결도는 그 방에 직접 들어갔을 때 확인한다.

## 상태 전이 및 예외 처리

- 판 생성 전에는 점수를 비워 둔다. `MatchBootstrap.MatchStarted`에서 세션을 연결하고, 이미 시작된 판에 HUD가 활성화되면 현재 상태를 즉시 읽는다.
- 판정 구역이 있을 때만 해당 ID로 점수를 조회한다. 졸개 배정·방문 기록이나 이전에 방문한 방을 통해 다른 구역의 수치를 조회하지 않는다. 시설 전체 점수는 구역 밖에서도 계속 보인다.
- 패널을 접었다가 펼치면 최신 상태를 표시한다. 비활성화 시 입력 구독을 해제해 씬 재시작 후 Tab 입력이 중복되지 않게 한다.

## 설계와 참조 데이터

- `4_Prefab/UI/UI_HudRoot`를 Facility 씬에 배치한다. uGUI Canvas에 위 네 패널을 중첩하고 글자는 TextMeshPro 한글 폰트로 표시한다. 직접 청소 중에는 현황 바로 위 중앙에 `UI_WorkGauge`를 표시한다. 상호작용으로 열리는 `UI_AssignmentPanel`과 B6 메시지도 하단 HUD를 기준으로 배치한다.
- 현재 `Runtime/UI/FacilityHud`가 지역명·지역 진척도, 시간·전체 진행도 및 대화 시 9개 구역 선택과 취소를 연결한다. `MinionStatusPanel`은 하단 현황을 작업자 타입으로 연결한다. 헬하운드 메시지는 B6 공용 영역에서 표시한다. `FacilityHud`는 `UI_WorkGauge`의 채움 비율을 작업 진행도에 맞춘다. 현재 구역·담당 방 표기는 기존 `ZoneDisplayName`을 사용한다.
- 시간과 기준은 실제 판의 읽기 계약을 사용한다. 현재 데이터는 180초, 구역 60%, 시설 85%다. HUD에 수치를 상수로 복제하거나 구역 점수의 평균으로 시설 점수를 재계산하지 않는다.
- 기존 Tab 바인딩을 사용한다. 정식 HUD와 겹치는 `DebugMatchOverlay` 상태 표시는 기본 게임 화면에서 끈다. B6 이전의 디버그 배정 기능은 개발용으로만 유지한다.

## DemonKingCountdown 타이머 연결

- 실제 카운트다운은 DemonKingCountdown 프리팹을 UI_HudRoot의 중첩 프리팹으로 배치한다.
- FacilityHud의 직렬화 참조로 연결하고 독립 자동 재생을 끈다. 최초 표시에서 세션 남은 시간으로 초기화하고 이후 같은 세션 시간으로 숫자와 연출을 갱신한다.
- 기존 UI_MatchTimer는 HUD에서 비활성화한다. 마감 연출과 결과 화면에서 새 타이머도 게임 HUD와 함께 숨긴다.
- 확인은 실제 판의 표시와 시간 동기화만 짧게 수행한다.

## 졸개 현황 카드 표현

- 고블린·오크·스켈레톤·슬라임은 고블린 카드의 종이 배경, 초상화 프레임, 보라색 명패와 동일한 배치를 사용한다. 초상화와 이름은 각 졸개에 맞춘다.
- 담당 지역과 현재 행동은 종이 위에서 읽히는 짙은 잉크색으로 표시한다. 현황 갱신과 Tab 접기·펼치기는 기존 규칙을 유지한다.
