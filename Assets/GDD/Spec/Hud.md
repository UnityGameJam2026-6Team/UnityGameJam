# B5 HUD 스펙

- 상태: 검토 대기 (D5 타이머 형식 포함)
- 근거: 게임플레이 기획 §2·§8·§9, B 레인 실행 계획 B5, Undecided U4·U21, DesignIssue D5
- 범위: Facility 플레이 중 상시 HUD와 플레이어 작업 게이지. 배정·제안은 B6, 마감 연출과 결과는 B7에서 연결한다.
- 네임스페이스: `UnityGameJam.UI`

## 목적

플레이어는 남은 시간과 시설 전체 점수를 보며 다음 행동을 고른다. 개별 방의 청결도는 그 방에 직접 들어갔을 때 확인한다.

## 입력 / 출력 및 표시 규칙

| 규칙 | 위치 · 출력 | 입력 | 동작 |
|---|---|---|---|
| 1 | 상단 중앙 첫 줄 · `UI_MatchTimer` | `RemainingTime` | 현재는 시:분:초 두 자리로 표시한다. D5 변경안은 분:초 두 자리다. 남은 초를 올림해 현재 형식에서는 180초는 00:03:00, 마지막 0.1초는 00:00:01, 종료는 00:00:00으로 표시한다. 대화 중에도 세션 시간을 그대로 읽는다. |
| 2 | 좌측 상단 첫 줄 지역명 · 둘째 줄 지역 진척도 · `UI_ZoneHud` | 플레이어 몸의 층, `PlayerZone`, `GetZoneCleanliness`, `ZoneThreshold` | 현재 층과 장소, 청결도, 기준값을 표시한다. 로비 이름에 층을 두 번 붙이지 않는다. 화장실·계단 등 판정 구역 밖에서는 현재 층을 유지하고 구역 점수·기준·미달 표시를 함께 숨긴다. 이전 방 점수를 남기지 않는다. |
| 3 | 상단 중앙 둘째 줄 · `UI_FacilityHud` | `FacilityCleanliness`, `FacilityThreshold` | 시설 전체 점수를 표시한다. 구역·시설 모두 원래 값이 각 기준보다 작을 때만 ‘미달’로 표시한다. 기준과 같으면 통과다. 표시 반올림으로 기준에 도달한 것처럼 보이지 않게 한다. |
| 4 | 좌측 하단 · `UI_MinionStatusPanel` | `Minions`, `Player/ToggleMinionPanel` | 졸개 5종의 이름, 담당 방과 층, 현재 행동을 한국어로 표시한다. 미배정이면 담당 방을 ‘미배정’으로 표시한다. Tab을 한 번 누를 때마다 접기·펼치기를 전환한다. 담당 방의 점수·기준 미달 표시는 노출하지 않는다. |
| 5 | 작업 게이지 | `IsPlayerWorking`, `PlayerWorkProgress` | 작업 중에만 표시하고 0~100 값을 게이지에 반영한다. 완료·취소하면 숨기고 다음 작업은 새 진행도로 시작한다. |

## 상태 전이 및 예외 처리

- 판 생성 전에는 점수를 비워 둔다. `MatchBootstrap.MatchStarted`에서 세션을 연결하고, 이미 시작된 판에 HUD가 활성화되면 현재 상태를 즉시 읽는다.
- 판정 구역이 있을 때만 해당 ID로 점수를 조회한다. 졸개 배정·방문 기록이나 이전에 방문한 방을 통해 다른 구역의 수치를 조회하지 않는다. 시설 전체 점수는 구역 밖에서도 계속 보인다.
- 패널을 접었다가 펼치면 최신 상태를 표시한다. 비활성화 시 입력 구독을 해제해 씬 재시작 후 Tab 입력이 중복되지 않게 한다.

## 설계와 참조 데이터

- `4_Prefab/UI/UI_HudRoot`를 Facility 씬에 배치한다. uGUI Canvas에 위 네 패널을 중첩하고 글자는 TextMeshPro 한글 폰트로 표시한다. 직접 청소 중에는 하단 중앙에 `UI_WorkGauge`를 표시한다. 우측 하단에는 상호작용으로 열리는 `UI_AssignmentPanel`을 고정한다. B6 메시지가 함께 표시될 때에는 버튼을 가리지 않도록 선택 패널 위로 쌓는다.
- 현재 `Runtime/UI/FacilityHud`가 지역명·지역 진척도, 시간·전체 진행도 및 대화 시 9개 구역 선택과 취소를 연결한다. `MinionStatusPanel`은 좌측 하단에 졸개 5종의 현황을 표시한다. Tab으로 접으면 제목만 남고 펼치면 현재 배정과 행동을 다시 표시한다. `FacilityHud`는 `UI_WorkGauge`의 채움 비율을 작업 진행도에 맞춘다. 현재 구역·담당 방 표기는 기존 `ZoneDisplayName`을 사용한다.
- 시간과 기준은 실제 판의 읽기 계약을 사용한다. 현재 데이터는 180초, 구역 60%, 시설 85%다. HUD에 수치를 상수로 복제하거나 구역 점수의 평균으로 시설 점수를 재계산하지 않는다.
- 기존 Tab 바인딩을 사용한다. 정식 HUD와 겹치는 `DebugMatchOverlay` 상태 표시는 기본 게임 화면에서 끈다. B6 이전의 디버그 배정 기능은 개발용으로만 유지한다.

## 테스트 시나리오

| 규칙 | 조건·행동 | 기대 결과 |
|---|---|---|
| 1 | 시작, 59.1초, 0.1초, 종료 | 분:초 승인 시 각각 03:00, 01:00, 00:01, 00:00 |
| 2 | 휴게실 → 화장실 → 다른 구역 이동 | 현재 방 점수만 보이고 화장실에서 이전 방의 점수와 미달 표시가 사라진다. |
| 2·3 | 구역 59.9%·60%, 시설 84.9%·85% | 각 쌍에서 첫 값만 미달. 구역과 시설 판정이 독립적이다. |
| 4 | 다른 층에 졸개를 배정한 후 Tab 두 번 | 패널이 접혔다 펼쳐지며 담당 방·층·행동만 갱신된다. 원격 점수는 보이지 않는다. |
| 5 | 얼룩 닦기 시작 → 취소 → 재시작 → 완료 | 진행 중에만 게이지가 채워지고 취소·완료 시 숨는다. |

시간 표기와 기준 경계는 EditMode 테스트로, 배치·한글 글리프·입력·원격 정보 노출은 Facility 실제 판의 1920×1080 Game 뷰로 확인한다.
