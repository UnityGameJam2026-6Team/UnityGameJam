# 플레이어와 고블린의 이동·애니메이션 조정

- 상태 확정
- 근거 [플레이어](Player.md), [졸개 몸](MinionAgent.md), [오염 표시](ContaminationView.md), [아트 적용](ArtPipeline.md)
- 네임스페이스 `UnityGameJam.View`, `UnityGameJam.Editor`

## 목적

Unity의 `Tools > UnityGameJam > 레벨 디자인`에서 플레이어와 고블린의 이동 속도와 집기·내려놓기 배속을 조정한다.

## 규칙

1. 걷기, 달리기, 가벼운 물건 운반, 걸레 이동은 FBX에서 측정한 기준 속도에 배율을 적용한다. 플레이어의 두 손 운반에는 조정된 걷기 속도와 게임의 감속 규칙, 전용 배율을 적용한다. 보행 클립 재생 속도는 실제 이동 속도를 따른다.
2. 집기와 내려놓기는 같은 클립 구간을 정방향과 역방향으로 사용하며 배속을 따로 적용한다. 손 접촉 시점과 이동 잠금 해제는 실제 재생 시간에 맞춰 변한다.
3. 기본 배율은 1이다. 저장 버튼으로 `ViewSettings`에 기록한 값은 다음 Facility 판을 시작할 때 적용한다. 저장값 불러오기는 창의 입력을 마지막으로 저장한 값으로 복원한다.

## 테스트 시나리오

| 조건 | 기대 결과 |
|---|---|
| 걷기 배율과 두 손 운반 배율을 변경 | 게임의 감속 규칙이 적용된 최종 속도를 계산한다 |
| 집기 2배속 및 내려놓기 0.5배속 | 정·역방향 각각 손 접촉과 잠금 시간이 일치한다 |
| 접촉을 종료 시점 뒤로 설정 | 접촉 시점이 구간 안으로 보정된다 |
| 에디터에서 조정값 저장 및 불러오기 | 각 유닛의 조정값이 저장되고 새 판에서 사용된다 |
