# 졸개 지휘 기술

- 상태 **확정**
- 적용 씬 **Facility**
- 근거는 지휘 기술 요청과 [졸개 행동](MinionBrain.md), [작업 제안](Proposal.md) 규칙이다.

## 기술과 입력

| 키 | 기술 | 범위 | 효과 | 쿨다운 |
| --- | --- | --- | --- | --- |
| Q | 호통 | 고블린·오크·스켈레톤·슬라임 | 진행 중인 일을 중단하고 발동 위치로 집결 | 60초 |
| E | 증진 | 발동 순간 플레이어와 같은 방에 있는 졸개 | 행동·이동·애니메이션 속도 1.5배, 15초 | 90초 |

두 기술은 판 시작 시 사용 가능하다. 쿨다운은 발동에 성공하는 순간부터 판 시간으로 센다. E에 대상이 없거나 플레이어가 계단을 이동 중이면 발동을 거절하고 쿨다운을 소비하지 않는다. 방은 층과 실제 위치로 판단하며 로비도 한 구역으로 취급한다. 작업 지시창, 오프닝, 결과 화면에서는 해당 화면의 입력 우선순위를 따른다. 쿨다운 중 누르면 해당 아이콘과 남은 시간만 짧게 강조한다. 다시 하기를 누르면 쿨다운과 효과를 초기화한다.

## Q 호통

1. 발동 순간 플레이어의 위치를 집결지로 고정한다. 계단 경로와 NavMesh를 따라 이동하고, 도착 지점을 조금씩 분산해 캐릭터가 겹치지 않게 한다.
2. 접근·탐색·걸레질을 중단하고 작업 선점을 해제한다. 미완료 작업은 점수를 받기 전 상태로 유지한다. 운반물은 작업자가 있던 자리에서 내려놓고, 빌린 걸레는 대여 재고에 반납한다. 슬라임은 이동하면서 이미 시작한 소화를 계속한다.
3. 응답 대기 중인 제안·합동 작업과 기존 배정을 정리한다.
4. 헬하운드는 호통 범위에서 제외되며 현관 대기와 배출 왕복 동선을 사용한다.
5. 도착한 졸개는 집결지에서 로비 대기 상태로 전환한다. 플레이어가 다음 작업을 지시할 때까지 기다린다.
6. 경로가 막히면 발동 좌표로 한 번 다시 시도한다. 재시도도 실패하면 도착할 수 있었던 위치에서 대기한다.

## E 증진

1. 발동 순간 같은 층의 같은 방에 있는 졸개를 확정한다. 대상은 방을 나가도 남은 효과를 유지하며, 발동 이후 들어온 졸개는 다음 발동 때 판정한다. 헬하운드도 같은 기준을 적용한다.
2. 대상 졸개의 이동, 걸레질, 슬라임 소화, 집기·놓기 접촉 시간, 배출 왕복에 해당하는 작업 시간을 1.5배로 진행한다. 효과 지속 시간, 마왕 타이머, 두 기술 쿨다운, 제안 제한 시간은 판 시간으로 센다.
3. 걸음 애니메이션은 실제 이동 속도에 이미 맞춰 재생되므로 이동 배율을 한 번만 반영한다. 제자리 작업과 집기·놓기는 작업 진행 속도에 맞춰 재생한다. 효과가 끝나거나 이동 중에 적용되어도 진행 중인 동작의 재생 위치를 보존한다.
4. 호통 이동 중에도 증진을 적용할 수 있다. 두 기술은 쿨다운을 각각 계산한다.

## HUD와 아이콘

- 화면 **우측 상단**에 Q, E 순으로 **1:1 정사각 슬롯 2개**를 배치한다. 1920×1080 기준으로 80×80 슬롯부터 잡고, 이름을 아래에 붙인다. 중앙 타이머 날개와 오른쪽 대화·작업 지시 패널에 여백을 둔다. 4:3, 16:9, 21:9에서 확인한다.
- 기존 붉은 봉인·보라색 이름표 계열의 어두운 프레임을 사용한다. **Q는 뿔나팔과 퍼지는 파문**, **E는 번개와 위쪽 화살표**로 그린다. 색을 구분하지 않아도 외곽 실루엣과 키 문자로 읽을 수 있게 한다. 아이콘 2종은 시안 확인 후 적용한다.
- 사용 가능 상태에서는 아이콘을 밝게 표시한다. 사용 직후 어두운 원형 마스크와 흰색 남은 시간을 `1:00`, `1:30`, `0:09` 형식으로 표시한다. 완료 시 프레임이 한 번 밝아진다. E의 **효과 0:15**는 슬롯 아래에 얇은 별도 바로 표시해 쿨다운과 구분한다.
- 영향받은 졸개마다 기존 하단 HUD의 알림 메시지 형식으로 한마디를 출력한다. 고블린은 친근하게, 오크는 간단명료하게, 스켈레톤은 정중하게, 슬라임은 “꿀렁”을 섞어 말한다. 상시 카드에는 배정 구역과 현재 행동을 계속 표시한다.
- 호통 이동 중에는 카드에 **집결 중**, 도착 뒤에는 **대기**를 표시한다. 증진 중에는 현재 행동 옆에 **↑**를 표시한다. 증진을 받은 헬하운드는 다른 일반 알림처럼 하단 공용 메시지 칸에 반응한다.

## 발동 연출

| 기술 | 발동 순간 | 지속 및 해제 |
| --- | --- | --- |
| 호통 | 낮은 나팔 음색과 함께 집결지에서 붉은 바닥 충격파를 두 번 낸다. | 이동과 도착 상태는 하단 현황에 표시한다. |
| 증진 | 금빛·보라색 파장이 같은 방에 퍼지고, 대상 졸개 발밑에서 빛이 위로 솟는다. 짧은 상승음과 낮은 타격음을 함께 낸다. | 15초 동안 초상화 테두리와 발밑 표식을 약하게 빛낸다. 효과가 끝날 때 표식이 줄어들며 사라진다. |

판정과 첫 충격파는 발동에 맞춘다. 카메라 위치·줌은 기존 이동과 대화 연출을 사용한다. 작업 대상 발광과 제자리 안내가 계속 보이도록 지속 효과의 크기와 불투명도를 낮춘다.

## 구현 순서

1. **게임 규칙** · `MatchSimulation`에서 사용 조건, 독립 쿨다운과 E 대상별 만료를 관리한다. 수치는 기존 게임 규칙 데이터에 둔다. `MinionBrain`에 집결·대기·복귀를 연결하고 헬하운드 배출 전이와 분리한다.
2. **입력과 애니메이션** · 기존 Player Input Action Map에 Q/E를 추가하고, 판 세션으로 명령을 넘긴다. 실제 이동·작업 배율을 `MinionAgent`와 `CharacterAnimatorDriver`에 일관되게 연결한다.
3. **HUD와 연출** · `UI_HudRoot`에 두 슬롯을 배치한다. `FacilityHud`와 하단 졸개 카드에는 실제 발동·대상·남은 시간만 전달하고, 해당 결과로 발동음·이펙트와 한마디를 재생한다.

## 검증

| 항목 | 확인할 조건 |
| --- | --- |
| 호통 기본 | 접근·걸레질·운반·소화·제안 대기 중인 일반 졸개가 발동 좌표로 모인다. 헬하운드는 기존 동선을 사용한다. 들고 있던 물건과 진행 중인 소화는 중복 정산되지 않는다. |
| 집결 대기 | 새 작업을 지시하기 전까지 도착한 졸개가 로비 대기 상태로 남는다. |
| 증진 대상 | 같은 방의 졸개만 적용된다. 벽 너머, 다른 층, 발동 이후 입장, 대상 없음 조건을 각각 검사한다. |
| 시간·애니메이션 | 정확히 15초 후 배율이 돌아온다. 중간 적용·해제에서 발걸음, 걸레 접촉, 운반물 접촉이 튀지 않는다. 두 쿨다운이 독립적이다. |
| HUD | 실제 영향을 받은 졸개만 반응한다. 4:3, 16:9, 21:9에서 타이머·작업 지시·제안 버튼과 겹치지 않는다. |
| 판 전환 | 시작 직후, 결과 화면, 다시 하기에서 쿨다운과 진행 중인 효과의 상태가 올바르다. |

게임 규칙은 EditMode에서 먼저 검증한다. 이펙트·음량·모션의 체감은 플레이 화면 확인 항목이다.
