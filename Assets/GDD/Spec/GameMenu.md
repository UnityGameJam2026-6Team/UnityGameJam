# ESC 설정과 조작 모드 스펙

- 상태: 확정 (사용자 요청 · 2026-11-19)
- 근거: 인게임 ESC 메뉴, 기존 한 장 도움말 표시, 양손과 Space·마우스 조작 전환 요청
- 범위: 설정 창, 도움말 보기, 조작 모드 저장, 타이틀 이동과 종료. 게임의 점수·배정 규칙은 유지한다.
- 네임스페이스: UnityGameJam.UI

## 규칙
1. 인게임에서 ESC를 누르면 설정 창을 열고 타이머·시뮬레이션·이동을 일시정지한다. 다시 ESC 또는 계속하기로 복원한다. 대화 중에도 기존 방 선택을 유지한다.
2. 도움말 버튼은 기존 한 장 가이드 PNG를 표시한다. 확대·축소·전체 보기와 드래그·스크롤을 지원하며 ESC는 도움말에서 설정 창으로 돌아온다.
3. 기본 양손 모드는 WASD 이동, J 상호작용, J/K 선택 확인, K/Y 제안 확인과 L/N 보류를 지원한다. 한손+마우스 모드는 WASD 이동, Space 상호작용·선택 확인, 마우스 클릭으로 제안·방 선택·취소를 처리한다. 기존 게임패드 바인딩은 유지한다.
4. 조작키 버튼을 누를 때마다 두 모드를 전환하고 PlayerPrefs에 저장한다. 다음 판에도 적용한다. 활성 모드에 맞게 제안 버튼 안내를 갱신한다.
5. 타이틀로 나가기는 TitleScene을 불러온다. 게임 종료는 빌드에서 Application.Quit, 에디터에서는 Play Mode 종료로 처리한다. 이동·종료 전에 일시정지 상태를 복원한다.
6. 설정이 열린 동안 배경 HUD·대화·제안·결과 버튼의 키보드 및 마우스 입력을 막는다. 닫은 프레임의 확인 입력은 게임으로 전달하지 않는다. 마왕 등장·전체 완료 연출 도중에는 새 설정 창을 열지 않는다.

## 설계
- UI_GameMenu 프리팹을 UI_HudRoot에 중첩한다. 기존 종이·뿔 프레임과 버튼 에셋, TMP 폰트, UI 효과음을 사용한다.
- GameMenu는 ESC 입력, 메뉴, 일시정지 복원, 도움말 확대와 씬 이동을 담당한다.
- GameControlSettings는 조작 모드 저장과 Input System 바인딩 오버라이드를 담당한다. 에셋의 기본 키를 런타임에 파괴하지 않는다.
- GameMenu/Pause 액션은 ESC에 연결하고 Player 맵과 별도로 활성화한다.
- 도움말 이미지는 5_Art/Sprite/OnePageGuide.png로 프로젝트에 포함한다. 한손 모드의 차이는 도움말 상단에 별도로 표시한다.

## 예외 처리
- 비활성화·씬 전환·Play Mode 종료에서도 시간 배율과 입력을 복원한다.
- 타이틀 씬이 빌드 목록에 없으면 이동하지 않고 콘솔에 원인을 표시한다.
- 설정 창 진입 전의 UI 선택을 기억하고 닫을 때 복원한다. 도움말·설정 위에는 다른 게임 패널이 입력을 받지 않는다.

## 검증
- ESC 열기/닫기 전후 타이머·플레이어 위치가 정지/재개되는지 짧게 확인한다.
- 도움말 이미지 표시, 확대·축소·전체 보기 및 ESC 복귀를 확인한다.
- 양손↔한손 전환 뒤 Space와 J, 제안 버튼 클릭 및 저장값 재적용을 확인한다.
- 대화 중 설정을 열어도 방 선택이 유지되는지 확인한다.
- 타이틀 이동과 에디터 종료 버튼을 확인하고 콘솔 에러 0을 확인한다.
