# 판 흐름과 마감 스펙

- 상태: 확정
- 근거: GDD §1·§7.2·§8·§10, U15, A1에서 확정한 D3
- 네임스페이스: `UnityGameJam.Match`, `UnityGameJam.Cleaning`

## 목적

180초가 끝나는 시점에 진행 중인 작업을 정리하고, 구역 9개와 시설 전체를 최종 판정한다. 계약을 통해 마감과 결과 상태를 알린다.

## 입력과 출력

`Tick(deltaTime)`, `GameRuleSO`, 청결도 계산기, 오염 레지스트리와 작업자별 현재 위치를 받는다. `RemainingTime`, `MatchStateChanged`, `MatchResult`를 제공한다.

## 규칙

1. `Ready → Running → DemonKingArrived → Resolved`의 상태 순서를 따른다. 준비 상태에서 시작을 한 번 받고, 시뮬레이션 시간은 최대 남은 시간까지만 진행한다.
2. 작업 완료·제안 만료·마감이 같은 틱에 겹치면 작업 완료 → 제안 만료 → 마감 순으로 처리한다(U15). 남은 시간을 초과한 프레임은 마감 시점 뒤의 작업을 완료 처리하지 않도록 남은 시간까지만 적용한다.
3. 마감 시작 이벤트를 한 번 내고 신규 명령을 막는다. 작업을 정지하고 각 작업자의 현재 위치·층에서 운반 중인 폐기물과 작은 물건을 내려놓는다(D3). 소화 중인 물건과 이미 출발한 배출 묶음은 계속 집계에서 제외한다.
4. 운반물 귀속 후 구역과 시설 전체 청결도를 기록한다. 설정의 구역 기준과 시설 기준을 모두 충족하면 성공이다. 결과 스냅샷을 저장하고 `Resolved` 이벤트를 한 번 낸다. B7이 마왕 등장 연출과 결과 UI를 호출한다.

## 설계

`MatchSimulation`이 틱 순서와 상태 알림을 관리하고 `MatchResolver`가 운반물 귀속과 점수 스냅샷을 만든다. 재시작은 새 팩토리 세션을 생성한다.
