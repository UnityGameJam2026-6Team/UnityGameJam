# B7 마왕 도착과 결과 화면

**확정 · B 레인 · `UnityGameJam.UI`**
근거는 게임플레이 기획 §8.1·§8.2, `Spec/MatchFlow.md`, B 레인 실행 계획 B7, U12·U15·U17이다.

## 플레이 흐름

플레이어는 마감 순간에 운반하던 폐기물이 어디에 놓였는지 본 뒤, 성공 여부와 기준에 못 미친 구역을 결과 화면에서 확인한다.

| 시점 | 화면과 조작 |
|---|---|
| 1. 판 진행 중 | 기존 HUD를 표시한다. 다른 방의 최종 점수와 다시 하기 버튼은 숨긴다. |
| 2. 마왕 도착 | 타이머가 0이 되고 `DemonKingArrived`를 받으면 플레이 조작을 잠그고 배정 패널·제안 카드를 닫는다. 현재 층의 카메라를 유지한 채 화면 안 플레이어 곁에 화이트박스 `CH_DemonKing`을 한 번 등장시킨다. 결과를 열기 전 약 1초 동안 마감된 현장을 보여 준다. |
| 3. 결과 표시 | 등장 연출이 끝나고 최종 결과가 준비되면 중앙의 `UI_ResultPanel`을 연다. 첫 줄에 ‘마왕 도착’과 ‘성공’ 또는 ‘실패’, 다음에 시설 전체 성적, 그 아래에 층별 9개 구역 성적을 표시한다. |
| 4. 다시 하기 | 결과 패널에서 ‘다시 하기’ 버튼을 누르거나 R을 새로 누르면 Facility 씬을 한 번 다시 불러온다. 새 판은 평소처럼 `MatchBootstrap`이 생성한다. |

마감 시 운반물의 귀속과 점수 계산은 A7이 끝낸다. 기존 `ContaminationView`가 최종 아이템 상태를 반영해 들고 있던 폐기물을 바닥에 표시한다. 작은 물건은 최종 점수에 귀속하며 전용 낙하 연출은 보류한다. 소화 중인 물건과 이미 배출을 시작한 묶음은 다시 나타나지 않는다.

## 결과 패널

- 전체 성공·실패는 `MatchResult.IsSuccess`, 시설 점수는 `FacilityCleanliness`, 구역별 점수는 `ZoneCleanliness`에서 읽는다.
- 각 행에 이름, 최종 청결도, 기준값, ‘통과’ 또는 ‘미달’을 표시한다. 판정에는 표시 전 원값과 세션의 `FacilityThreshold`·`ZoneThreshold`를 사용한다. 퍼센트 표시는 기존 HUD처럼 정수로 내림한다. 현재 `GameRule.asset`의 기준은 시설 85%, 구역 60%다.
- 행은 1층 로비·다목적실·휴게실·창고, 2층 로비·회의실·작업실, 3층 로비·간부실 순서로 배치한다. 이름과 층은 `ZoneDisplayName`을 사용한다.

## 구현 연결과 경계 조건

- `DemonKingArrivalView`는 `MatchBootstrap.MatchStarted`에서 세션에 연결하고 `MatchStateChanged`를 구독한다. 활성화 시 이미 시작된 세션의 현재 상태도 읽고 비활성화 시 구독을 해제한다. 마왕 프리팹은 인스턴스를 생성해 표시한다.
- 실제 판과 가짜 판 모두 한 번의 `Tick` 안에서 `DemonKingArrived`와 `Resolved`를 차례로 알린다. 도착 이벤트에서 연출을 시작하고 `Resolved`에서 결과를 보관한다. 연출 완료와 결과 수신이 모두 충족되면 `ResultPanel`을 한 번 연다. 이미 종료된 판에 뒤늦게 연결되면 저장된 결과를 표시한다.
- 마감과 배정 패널 닫힘이 겹쳐도 이동·상호작용·제안 응답 입력은 잠긴 상태를 유지한다. 결과가 표시된 뒤 새로 누른 R만 재시작 입력으로 받는다. 버튼과 키가 동시에 들어와도 씬 로드는 한 번만 요청한다.

## 구현 후 검증

| 규칙 | 검증 장면 | 기대 결과 |
|---|---|---|
| 1·2 | Facility에서 폐기물을 든 채 180초 마감. 다른 층과 배정 대화 중 마감도 확인 | 현재 층에서 마왕을 볼 수 있다. 운반물은 마지막 위치에 놓이고, 플레이 입력과 배정·제안 UI는 닫힌다. |
| 2·3 | 가짜 세션에서 같은 틱에 도착·판정 이벤트 발생 | 등장 장면을 볼 수 있고, 뒤이어 결과 패널 하나가 열린다. 재활성화 시 중복되지 않는다. |
| 3 | 시설 85%, 모든 구역 60% 이상 | 성공. 시설과 9개 구역에 모두 ‘통과’가 표시된다. |
| 3 | 시설 90%, 3층 로비 59%. 별도 판에서 모든 구역 통과, 시설 84.9% | 첫 판은 3층 로비, 두 번째 판은 시설 행이 ‘미달’이며 둘 다 실패다. |
| 4 | 마감 전부터 R 유지 → 결과에서 키를 뗐다가 다시 누름. 별도로 버튼 클릭 | 결과를 읽을 수 있고 새 입력마다 한 판만 시작한다. 타이머와 HUD가 초기화되며 이전 결과·마왕은 사라진다. |
