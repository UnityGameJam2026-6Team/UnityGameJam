# 졸개 두뇌와 기억 스펙

- 상태: 확정
- 근거: GDD §5–7, U1·U2·U5·U6·U7·U9·U14·U101·U102, D2, `MinionAgent.md`
- 네임스페이스: `UnityGameJam.Minion`

## 목적

플레이어가 배정한 방에서 일반 졸개가 이동, 순찰, 청소를 반복한다. 관찰한 방의 상태와 다른 졸개의 담당 구역을 다음 방 선택에 사용한다.

## 입력과 출력

`MatchSetup.MinionBodies`, `FacilityLayout`, A1~A4의 오염·작업 선택·걸레·소화 서비스와 수치 에셋을 받는다. `MinionStatus`를 갱신하고 목표 방 제안이나 복귀 통보 요청을 A6에 보낸다.

## 규칙

1. 일반 졸개는 1층 로비에서 대기한다. 대화 중 멈추고 새 배정이 확정되면 작업 선점을 풀고 운반물을 현재 위치에 내려놓는다. 걸레가 있으면 빌린 화장실에 반납한 뒤 새 방으로 간다. 대화를 취소하면 기존 행동과 남은 작업 시간을 이어가고, 그 사이 대상을 잃었으면 다시 찾는다(U9). 소화는 대화 중에도 진행한다.
2. 방에 진입하고 관찰 가능한 작업을 먼저 고른다. 보이는 작업이 없으면 저작된 순찰 경로를 한 바퀴 돈다. 관찰은 배정 구역 안에서 XZ 거리 5m 이내다(U104). 이 거리는 데이터 에셋에서 읽는다. 5m로 탐색한 결과만 방 기억에 반영하며, 순찰을 마칠 때까지 아직 보지 않은 위치의 오염은 미확인 상태로 취급한다.
3. 작업은 A3의 유형·거리 우선순위로 고른다. 대상에게 실제로 작업을 시작할 때 선점한다. 운반은 작은 물건이면 원래 슬롯, 폐기물이면 1층 현관 배출 지점에 놓는다. 그 뒤 원래 방에 복귀한다. 플레이어가 대상을 가로채거나 대상이 사라지면 현재 배정 구역에서 다시 판단한다.
4. 얼룩을 찾으면 걸레를 빌리고 원래 방을 다시 관찰한다. 걸레가 있을 때는 얼룩만 닦는다. 일을 마치거나 재배정되면 빌린 화장실에 반납부터 한다. 슬라임은 소화 중에도 이동할 수 있고 소화가 끝날 때까지 새 작업을 시작하지 않는다. 기존 스냅샷의 `Digesting` 상태와 `Carrier=Slime`을 유지한다.
5. 이동은 `IMinionBody.MoveTo(층, 위치)`로 요청한다. `HasArrived`를 읽어 다음 행동으로 진행한다. B의 몸이 계단 이동과 `ViewSettingsSO`의 현재 2초 대기를 관리한다.
6. 배정받아 들어간 방만 기억하고, 외부 청소로 기억을 자동 갱신하지 않는다(U14). 다른 졸개가 어느 방에서 일하는지와 화장실별 걸레 재고를 안다(D2). 다른 졸개의 위치는 그 방의 최신 오염을 알려주지 않는다.
7. 같은 층을 각 후보군 안에서 우선한다. U6 순서대로 기억상 자신이 할 일이 있는 방, 미확인 방, 다른 졸개가 일하는 방을 찾는다. 현재 방과 기억상 깨끗한 방을 빼고, 같은 조건이면 구역 ID 순으로 고른다. 후보가 없으면 복귀 통보를 보내고, 보류·만료 시에도 로비로 간다.

## 설계

`MinionBrain`이 상태 전이, 목적지, 배정 ID를 관리한다. `MinionMemory`는 방별 관찰 기록만 보관하고 `ProposalCandidateFinder`가 후보를 고른다. 몸과 툴은 기존 계약과 서비스로 호출한다.
