# 사운드 연결 스펙

근거는 사용자 제공 Demon_King_Cleaning_Audio_List_and_Unity_AI_Prompts.md의 상황별 재생표와 7~9절이다. SFX 폴더의 기존 WAV 65개와 추가 제작한 WAV 7개를 타이틀과 Facility의 라이브러리에서 사용한다. 미결 질문 없음.

- SfxLibrarySO에 클립, 개별 음량, 거리, 동시 재생 수, 보행 간격을 저장한다. 실제 파일을 참조하며 런타임 파일 이름 검색으로 소리를 불러오지 않는다.
- GameSfxPlayer가 UI·시간·결과의 2D 소리와 가까운 월드 위치의 3D 소리, 공통 환경음 한 개, 걸레질 루프를 재생한다. 리스너는 플레이어 높이를 따라가고 기존 카메라 리스너는 해당 판 동안 끈다.
- GameAudioPresenter가 실제 상태 전이를 읽고 집기·내려놓기·걸레 대여·반납을 손 접촉에 맞춰 재생한다. 제자리 정리에만 정리 완료음을 더한다. 취소된 걸레질에는 완료음이 없다.
- 플레이어·고블린은 가벼운 발소리, 오크·마왕은 무거운 발소리, 스켈레톤·슬라임·헬하운드는 각 세트를 쓴다. 실제 이동 중에만 보행 주기 또는 이동 거리를 따라 재생하고 계단 순간 이동·벽에 막힘·대화에는 반복하지 않는다.
- 다른 층과 아직 가려진 방의 작업 소리는 들리지 않는다. 월드음·발소리·AI 걸레질 루프는 동시 재생 수를 제한한다.
- 이동 제안과 통보는 MessageId마다 한 번 알린다. 여러 건이 동시에 도착하면 제안 한 음을 우선한다. 현재 응답 대상의 자연 만료만 작은 만료음을 내고 사용자 응답·재배정·종료로 지워지는 카드는 제외한다.
- UI 확정·취소는 성공한 명령에 연결하고 패널 종료와 중복하지 않는다. 헬하운드 거절은 수행 불가음 한 번으로 안내하며 새 통보음과 겹치지 않는다.
- 60초, 50·40·30·20·10초, 3·2·1초 경고는 세션 시간을 따른다. 100% 완료 후 빠른 카운트다운에는 건너뛴 경고를 몰아 재생하지 않는다. 마왕 도착음은 한 번이고 결과 징글은 결과 화면 공개 때 성공 여부에 따라 한 번 재생한다.
- 로고 인트로의 착지 이벤트와 서류판의 실제 열기·닫기 이벤트에 연결한다. 대기 반복 장식은 무음이다.
- 로딩 만화는 새 입력으로 컷이 공개될 때, 판 오프닝은 숫자 5~1이 바뀔 때 각각 한 번 재생한다. 조작이 시작되는 순간에는 기존 판 시작음을 재생한다.
- Q 호통과 E 증진은 발동 성공의 첫 파장에 전용 WAV를 한 번 재생한다.
- 현관 컷에서 문이 열릴 때, 헬하운드가 멈춰 반길 때, 실패 컷의 쓰레기가 손을 떠날 때 전용 WAV를 한 번씩 재생한다. 컷의 발소리, 쓰레기 적중음과 결과 징글은 기존 WAV를 쓴다.
- 재시작은 이전 씬의 재생기와 루프를 함께 정리하고 새 판에서 시작음과 환경음 한 개를 재생한다.
- 기존 BGM 파일은 현재 제공되지 않았다. 오디오 믹서의 새 구조와 새로운 상호작용은 만들지 않는다.
- 검증은 클립 참조·컴파일과 대표적인 UI, 집기·정리, 걸레질 시작·취소, 시간·결과 재생 흐름만 짧게 확인한다. 최종 음량과 루프의 청음은 실제 스피커에서 조절할 수 있다.
