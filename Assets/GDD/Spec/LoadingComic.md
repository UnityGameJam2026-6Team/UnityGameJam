# 타이틀 로딩 만화 스펙

- 상태 **확정**
- 담당 **B 레인 월드·표현**
- 네임스페이스 `UnityGameJam.UI`
- 근거는 닉네임 확정 후 표시하는 사용자 승인 만화와 기존 `TitleMenu` 씬 전환 흐름이다.

## 목적

마왕군 간부가 지키는 외곽 감시초소가 방치된 이유와 급히 청소하는 계기를 플레이 전에 보여 준다.

## 컷과 규칙

| 번호 | PNG | 내용 | 1920×1080 좌상단 기준 영역 |
|---:|---|---|---|
| 1 | `Comic_01_Outpost` | 평화로운 외곽 감시초소 | `0, 0, 911, 518` |
| 2 | `Comic_02_Idle` | 일을 대충 하며 카드놀이하는 간부와 졸개 | `911, 0, 1009, 518` |
| 3 | `Comic_03_Message` | 마왕의 갑작스러운 방문 연락 | `0, 518, 516, 562` |
| 4 | `Comic_04_Panic` | 방치한 시설을 보고 놀란 플레이어 | `516, 518, 618, 562` |
| 5 | `Comic_05_Cleanup` | 플레이어가 먼저 물걸레질을 시작하고 졸개들이 합류 | `1134, 518, 786, 562` |

1. 타이틀에서 닉네임을 확정하면 화면을 어둡게 하고 기존 게임 씬을 비동기로 불러온다. 씬 활성화는 만화를 다 본 뒤까지 대기한다.
2. 만화는 16:9 프레임에 배치한다. 만화가 열린 뒤 첫 키부터 입력 한 번에 한 컷을 위 순서로 공개한다. 새 컷은 짧게 페이드 인되며 작게 시작해 원래 크기로 자리 잡고, 이전 컷은 남는다.
3. 닉네임 확정 입력과 누르고 있는 키는 컷 넘김에 재사용하지 않는다. 컷이 나타나는 짧은 구간에는 다음 입력을 대기시킨다.
4. 다섯 번째 컷이 완전히 나타나면 시작 안내를 표시한다. 다음 키를 받으면 만화를 닫고, 로드가 완료된 게임 씬에서 기존 오프닝 카운트다운으로 이어진다. 로딩이 남아 있으면 기존 로딩 문구를 표시한다.

## 설계

- `TitleMenu`의 닉네임 확정 콜백과 씬 전환을 재사용한다. Input System의 키보드에서 새로 눌린 키를 확인한다.
- `UI_TitleMenu`의 `SceneFade` 안에 `LoadingComic`을 두고, 16:9 영역에 사선으로 자른 다섯 `ComicPanelImage`와 각 컷의 굵은 흰 테두리, `CanvasGroup`을 배치한다. 컷 사이와 아래쪽은 같은 검은 배경을 사용하고 키 안내는 빈 공간에 흰 글자로 표시한다.
- PNG는 `5_Art/Sprite/LoadingComic`에서 각각 단일 Sprite, 가운데 피벗, 100 PPU로 임포트한다.

## 검증 시나리오

| 규칙 | 확인 내용 |
|---:|---|
| 1 | 닉네임을 확정하면 타이틀을 페이드 아웃하고, Facility 씬 활성화 전에 만화가 열린다. |
| 2 | 새 키로 1~5컷을 위 왼쪽부터 아래 오른쪽 순서로 공개한다. 앞 컷이 화면에 남고 여백과 글자가 잘리지 않는다. |
| 3 | 닉네임 확정 Enter를 누른 채 있어도 첫 컷이 자동으로 표시되지 않는다. 키 한 번에 한 컷만 공개한다. |
| 4 | 다섯 번째 컷 뒤 새 키를 받으면 만화가 닫히고, 게임 카운트다운이 시작된다. |
