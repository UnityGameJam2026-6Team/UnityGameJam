# 도구·배출·소화 스펙

- 상태: 확정
- 근거 문서: GDD §3.1, §4, §7.1–2, §8.2, §10 / `Undecided.md` U5·U16·U102·U103 / A3의 U101
- 담당: A4 · A 레인
- 네임스페이스: `UnityGameJam.Minion`

## 목적

화장실별 물걸레의 대여 상태를 관리한다. 헬하운드가 출발할 때 현관의 폐기물 묶음을 점수에서 제외하고, 슬라임이 먹은 폐기물의 소화 시간을 진행한다.

## 입력과 출력

| 구분 | 이름 | 설명 |
|---|---|---|
| 입력 | `FacilityLayout.Toilets` | 층별 화장실과 걸레 대여 위치 |
| 입력 | `GameRuleSO` | 화장실별 걸레 수(2개)와 대여·반납 상호작용 거리 |
| 입력 | `WorkerStatsSO` | 슬라임 소화 시간, 헬하운드 배출 왕복 시간 |
| 입력 | `ContaminationRegistry` | 배출과 소화에 따른 개체 상태 변경 |
| 출력 | 대여·반납 결과와 화장실 | 현재 보유 상태, 이동해야 할 화장실의 층과 위치 |
| 출력 | 배출·소화 결과와 진행 상태 | A5 행동과 A6 안내에 필요한 결과 |

## 규칙

1. 각 층 화장실은 물걸레 2개를 가진다. 한 작업자는 한 번에 걸레 하나를 빌린다. 작업자는 화장실의 걸레 위치에 상호작용 거리만큼 접근해 빌리며, 출발할 때 조회한 걸레가 그사이에 대여되면 도착한 시점의 재고로 다시 판단한다. 걸레를 쓰는 작업자와 운반 중인 물건의 상호작용은 A3 능력과 세션이 판단한다.
2. 졸개가 갈 화장실은 현재 층을 우선한다. 현재 층에 걸레가 없으면 층 차가 가장 작은 곳을 찾고, 층 차가 같으면 낮은 층을 고른다(U102). 어느 층에도 걸레가 없으면 대여할 곳 없음으로 결과를 반환한다. 다른 방 제안 또는 로비 복귀는 A5에서 연결한다.
3. 졸개는 할 일이 끝나거나 재배정되면 빌린 화장실에 먼저 반납한 뒤 제안하거나 이동한다(U5). 플레이어도 빌린 화장실에서 반납한다(U103). 걸레는 여러 얼룩에 쓸 수 있다. 반납이 성공하면 빌린 화장실의 재고가 즉시 회복된다. 졸개가 반납 지점에 닿지 못하면 한 번 다시 시도한다. 다시 실패하면 빌린 화장실의 재고를 회복한 뒤 제안하거나 새 방으로 이동한다.
4. 헬하운드에게 대면 명령을 내리면 현재 배출 구역에 적치된 폐기물을 한 묶음으로 배출한다. 출발 즉시 A1 레지스트리가 묶음을 점수에서 제외한다. 헬하운드는 배출 구역을 향해 달리고 설정된 왕복 시간의 절반이 되면 현관 대기 위치로 달려 돌아온다. 왕복 시간이 지나고 몸이 대기 위치에 도착하면 다음 명령을 받는다. 출발 후 새로 적치된 폐기물은 다음 명령에서 가져간다.
5. 헬하운드가 배출 중이거나 배출 구역이 비었으면 작업을 시작하지 않는다. A4는 두 사유를 다른 결과로 반환한다. A6은 사유별 안내를 표시한다(U16). 두 사유가 겹치면 배출 중을 우선한다.
6. 슬라임이 처리할 수 있는 폐기물을 먹으면 즉시 `Digesting`이 되고 점수에서 제외된다. A3에서 정한 현관 적치 규칙도 적용된다. 소화는 한 번에 한 건이며, 남은 시간에 따른 이동은 A5가 처리한다. 소화 시간이 끝나면 A1 레지스트리가 `Resolved`로 바꾼다. 마감 시 소화 중인 폐기물은 점수에 다시 포함되지 않는다.

## 상태 전이

| 대상 | 전이 |
|---|---|
| 걸레 | 화장실 재고 → 대여 중 → 빌린 화장실 재고 |
| 헬하운드 | 현관 대기 → 배출 이동 → 왕복 시간 이후 현관 대기 |
| 슬라임 | 소화할 개체 없음 → 폐기물 한 건 소화 중 → 소화할 개체 없음 |

## 예외 처리

- 재고 없음, 이미 대여 중, 반납할 수 없는 화장실, 보유한 걸레 없음은 각각 실패를 반환하고 재고를 유지한다.
- 두 번째 소화 요청 또는 대상이 이미 다른 작업자에게 선점되거나 처리된 경우 A1 레지스트리의 상태를 따른다.
- 음수·유한하지 않은 경과 시간은 잘못된 호출로 처리한다.

## 설계

| 파일 | 역할 |
|---|---|
| `Runtime/Minion/MopStationService.cs` | 재고 조회, 화장실 선택, 대여와 반납 처리 |
| `Runtime/Minion/DischargeService.cs` | 배출 명령 결과, 출발 시 적치 묶음 반영, 왕복 시간 |
| `Runtime/Minion/SlimeDigestion.cs` | 소화 가능 여부, 소화 시작과 완료 시간 |
| `Runtime/Data/GameRuleSO.cs` 및 `GameRule.asset` | 화장실당 걸레 수 2개를 추가한다. |

M1은 A4 서비스와 실제 세션을 연결한다. A5는 졸개가 대여·반납 위치로 이동하고 소화 중에도 이동할 수 있게 연결한다. A6은 배출 명령 결과를 플레이어에게 표시한다.

## 미정·보류

- D2의 졸개 인지 범위는 A5의 기억 스펙에서 확인한다.
- 현재 걸레질이 가능한 작업자는 플레이어·고블린·오크·스켈레톤 4종이다. 전체 재고가 소진되는 경우는 서비스 테스트에서 별도로 확인한다(D101).
