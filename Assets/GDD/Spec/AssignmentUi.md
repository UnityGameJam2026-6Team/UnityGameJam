# B6 대화와 제안 UI

게임플레이 기획 §6·§9, U9·U10, `Spec/Proposal.md`에 따른다. 배정, 응답 순서, 만료 판정은 세션이 담당하고 `UnityGameJam.UI`는 입력과 표시를 담당한다.

| 조건 | 표시와 동작 | 확인 방법 |
|---|---|---|
| 대화 상대 확인 | 제목에 ‘오크에게 맡길 곳’처럼 졸개 이름을 표시한다. 그 아래에 현재 담당 방의 층과 이름을 표시한다. 담당 방이 없으면 ‘미배정’으로 표시한다. | 처음 만난 졸개, 다른 층의 방을 맡긴 졸개, 다른 대화 상대에게 차례로 말을 걸어 두 줄을 확인한다. |
| 졸개와 대화 | 우측 하단에 9개 방을 표시하고 첫 방을 선택한다. 패널이 열린 동안 Player 맵의 입력을 잠근다. 방향키로 방을 고르고 Enter로 배정한다. 취소 버튼이나 Esc로 대화를 취소한다. 패널을 닫으면 열기 전에 활성화돼 있던 플레이어 입력을 복원한다. | 방향키로 버튼 선택이 바뀌는 동안 플레이어의 수평 위치가 유지되는지 확인한다. Enter로 배정하거나 Esc로 취소한 뒤 각각 이동을 다시 확인한다. |
| 이동 제안 도착 | 우측 하단의 새 카드가 기존 카드를 위로 민다. 졸개, 목적지의 층과 방, 대사, 남은 초와 게이지를 표시한다. | 서로 다른 시각에 도착한 두 제안의 게이지를 비교한다. |
| 제안과 통보가 함께 활성 | 계약의 목록 순서를 유지한다. 응답 대상만 강조하고 F 승인·R 보류를 표시한다. 복귀·배출 통보는 회색이며 응답을 받지 않는다. | 통보가 앞에 있어도 F와 R이 순서대로 제안 한 건씩만 처리하는지 확인한다. |
| 방 선택과 제안이 동시에 활성 | 카드 묶음을 방 선택 패널 위로 올린다. 대화 중에는 응답 키 안내를 숨긴다. 각 제안의 7초 타이머는 계속 흐른다. | 배정 패널을 열고 입력 차단, 게이지 감소, 만료를 확인한다. |
| 제안 응답·만료·판 종료 | 세션에서 사라진 카드를 걷고 다음 입력 대상을 표시한다. 판 종료 시 카드를 모두 숨긴다. | 응답 직후 및 판 마감 후 남은 카드 수를 확인한다. |

`UI_HudRoot` 아래의 `UI_ProposalStack`은 `ActiveMessages`와 `MessageEntry.IsInputTarget`을 읽는다. 게이지 비율은 표시 이후 경과 시간과 남은 시간으로 계산한다. F와 R은 기존 Player/Approve와 Player/Hold를 통해 세션 명령을 호출한다.
