# B6 대화와 제안 UI

게임플레이 기획 §6·§9, U9·U10, `Spec/Proposal.md`에 따른다. 배정, 응답 순서, 만료 판정은 세션이 담당하고 `UnityGameJam.UI`는 입력과 표시를 담당한다.

| 조건 | 표시와 동작 | 확인 방법 |
|---|---|---|
| 대화 상대 확인 | 제목에 ‘오크에게 맡길 곳’처럼 졸개 이름을 표시한다. 그 아래에 현재 담당 방의 층과 이름을 표시한다. 담당 방이 없으면 ‘미배정’으로 표시한다. | 처음 만난 졸개, 다른 층의 방을 맡긴 졸개, 다른 대화 상대에게 차례로 말을 걸어 두 줄을 확인한다. |
| 졸개와 대화 | 하단 졸개 현황 위에 9개 방을 표시하고 첫 방을 선택한다. 카메라는 두 캐릭터 사이로 이동하며 가까워진다. WS로 상하, AD로 좌우 선택을 옮기고 J/K로 확인, L로 취소한다. 패널이 닫히면 플레이어 조작과 카메라 추적을 복원한다. | 키보드로 버튼을 옮기는 동안 플레이어 위치가 유지되는지 확인한다. J/K와 L로 패널을 닫은 뒤 이동과 카메라 복귀를 확인한다. |
| 헬하운드와 대화 | 현관에서 J로 말을 걸면 배출·취소 버튼이 열린다. 배출을 선택했을 때만 기존 배출 명령을 전달한다. 두 버튼의 연결은 대화 패널 프리팹이 보관한다. | 처음 J로는 배출되지 않고, L로 취소한 뒤 이동이 복원되는지 확인한다. 적치한 폐기물을 배출한 뒤 일반 졸개에게 말을 걸면 방 목록이 표시되어야 한다. |
| 대화 카메라 전환 | 기존 화면의 좌우 방향을 유지한다. 대화 진입과 종료 시 초점, 거리, 기울기를 0.55초 동안 함께 보간한다. 벽이 정면을 가리면 더 위에서 내려다본다. | 일반 졸개와 헬하운드에게 여러 방향에서 말을 걸고 두 캐릭터가 중앙에 들어오는지 확인한다. 전환이 끝나기 전에 취소해도 끊김 없이 추적으로 돌아와야 한다. |
| 이동 제안 도착 | 발신 졸개 슬롯 위에 졸개, 목적지의 층과 방, 대사, 남은 초와 게이지를 표시한다. 현황 패널과 동일한 종이 배경으로 꾸미고 아래에서 위로 부드럽게 나타난다. 응답 대상은 확인 Y·보류 N 버튼으로 처리한다(K/L도 유지). 초과한 카드는 스크롤한다. | 서로 다른 졸개의 동시 제안과 한 졸개의 여러 메시지를 확인한다. |
| 제안과 통보가 함께 활성 | 계약의 목록 순서를 유지한다. 응답 대상만 강조하고 Y 확인·N 보류를 표시한다. 복귀·배출 통보도 같은 종이 배경을 사용하며 응답 버튼을 표시하지 않는다. 표시 중인 승인·보류 버튼은 카드의 ID가 현재 응답 대상일 때만 동작한다. | 통보가 앞에 있어도 Y와 N이 순서대로 제안 한 건씩만 처리하는지 확인한다. |
| 담당 작업 종료·복귀 | 졸개의 다음 방 제안이나 복귀 통보에 이전 담당 방에서 현재 할 수 있는 작업이 없다는 안내를 함께 표시한다. 헬하운드 통보는 졸개 메시지 바로 위 공용 영역으로 보낸다. | 제안과 복귀 통보에서 각각 이전 담당 방을 확인한다. Tab으로 현황을 접은 상태에서도 안내가 보여야 한다. |
| 방 선택과 제안이 동시에 활성 | 카드 묶음을 방 선택 패널 위로 올린다. 대화 중에는 응답 키 안내를 숨긴다. 각 제안의 7초 타이머는 계속 흐른다. | 배정 패널을 열고 입력 차단, 게이지 감소, 만료를 확인한다. |
| 제안 응답·만료·판 종료 | 확인·보류 명령은 즉시 세션에 전달한다. 확인에는 붉은 해골 도장, 보류에는 보라색 해골 도장을 해당 버튼 위에 찍는다. 도장을 잠시 보여 준 뒤 아래로 부드럽게 내려가며 사라진다. 응답한 카드의 퇴장 중에도 다음 입력 대상을 표시한다. 자연 만료는 도장 없이 내려간다. 판 종료 시 카드를 모두 숨긴다. | Y/N 입력 또는 클릭 직후 서로 다른 도장이 표시되는지, 응답 중복이 없는지, 퇴장 뒤 카드가 숨는지 확인한다. 판 마감 시 모든 카드를 즉시 숨긴다. |

`UI_HudRoot` 아래의 `UI_ProposalStack`은 `ActiveMessages`와 `MessageEntry.IsInputTarget`을 읽는다. 게이지 비율은 표시 이후 경과 시간과 남은 시간으로 계산한다. Y와 N은 각각 Player/Approve와 Player/Hold를 통해 세션 명령을 호출한다. 기존 K/L 바인딩도 유지한다. 카드는 메시지 ID로 관리하며 퇴장 중인 카드를 다음 메시지에 재사용하지 않는다. 등장 0.24초, 도장 0.14초·유지 0.35초, 퇴장 0.26초와 이동 거리 48은 ProposalCard 프리팹의 직렬화 값으로 조정한다.
