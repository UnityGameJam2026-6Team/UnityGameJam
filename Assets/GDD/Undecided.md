# 기획 미정 사항

아직 정해지지 않은 기획 내용을 적는다. 코드에서는 `// TODO: U<번호>`로 표시한다.

번호 대역: 공통 1번대, A 레인 100번대, B 레인 200번대 (`docs/rules/collaboration.md`). 대상 문서: `GDD/Demon_King_Cleaning_Gameplay_Spec.md` v0.3
U1~U19의 결정은 기획서에 반영했다. U12·U17의 추가 기획은 보류하며, U19의 최종 수치는 플레이테스트에서 조정한다.

| 번호 | 이름 | 내용 | 임시 처리 / 결정 | 상태 |
|---|---|---|---|---|
| U1 | 종별 능력 표 | 고블린과 오크도 물걸레질을 하는가? (D1) | **결정**: 고블린과 오크도 물걸레질을 한다. 오크는 완력이 강해 물걸레질이 느리다(물걸레질 시간을 길게, 값은 WorkerStatsSO). 스켈레톤은 물걸레질에 능숙하다(가장 빠름). 능력 표: 고블린(작은 물건 O, 일반 쓰레기 O, 무거운 잔해 X, 얼룩 O), 오크(O, O, O, O·느림), 스켈레톤(X, X, X, O), 슬라임(X, 먹기 O, 먹기 O, X), 플레이어(모두 O) | 결정 |
| U2 | 로비 배정 | 배정 목록에 로비 3곳이 들어가는가? | **결정**: 9개 구역 모두 배정할 수 있다. | 결정 |
| U3 | 작은 물건 제자리 | 작은 물건은 어디에 정리하는가? | 물건마다 처음 있던 구역에 고유한 제자리(HomeSlot)가 있다. 생성할 때 짝지은 그 자리에 돌려놓는다. | 결정 |
| U4 | HUD 최저치 | 좌측 상단의 "최저치"는 기준값(60%)인가, 이번 판에서 가장 낮았던 값인가? | **결정**: 기준값(60%)을 표시한다. | 결정 |
| U5 | 걸레 반납 | 플레이어는 걸레를 어떻게 반납하는가? 걸레를 든 졸개를 재배정하면 반납부터 하는가? (D8) | 플레이어는 빌렸던 화장실의 원래 걸레걸이에 반납한다. 졸개는 일이 끝나거나 재배정되면 먼저 빌린 곳에 반납한 뒤 제안하거나 새 구역으로 이동한다. | 결정 |
| U6 | 제안 후보 규칙 | 후보와 제외 조건, 우선순위 (D4) | **결정**: 기억상 자기가 할 일이 있는 방 → 미확인 방 탐색 → 다른 졸개가 일하는 방. 현재 방과 기억상 깨끗한 방은 뺀다. "근처"는 같은 층을 뜻한다. | 결정 |
| U7 | 같은 대상에 접근할 때 | 둘 이상이 같은 물건이나 얼룩을 발견하면 어떻게 하는가? | 다가가는 동안에는 누구나 같은 물건을 목표로 삼을 수 있다. 먼저 도착해 집으면 다른 작업자는 다른 대상을 찾는다. 걸레질은 실제로 닦기 시작할 때 담당자를 기록하며, 플레이어가 대신 맡아 닦을 수 있다. | 결정 |
| U8 | 구역 밖 귀속 | 화장실이나 계단에 떨어진 물건의 귀속 (D7) | **결정**: 그 층 로비에 귀속한다. | 결정 |
| U9 | 대화 취소 | 배정 대화를 취소하면? | 멈춘 행동과 작업 시간을 이어간다. 대상을 잃었으면 다시 판단한다. 이미 진행 중인 소화는 대화 중에도 진행한다. | 결정 |
| U10 | 배정 중 제안 입력 | 배정 패널이 열려 있을 때 승인·보류 입력을 받는가? | 승인·보류 입력은 막고 제안 만료 시간은 계속 흐른다. | 결정 |
| U11 | 키 배치 | 키보드 이동, 상호작용과 제안 응답 | WASD 이동, J 상호작용·내려놓기·도구 사용, 제안 K 승인·L 취소. 대화는 WS 상하·AD 좌우, J/K 확인, L 취소. | 결정 |
| U12 | 화면 흐름 | 타이틀, 결과 화면, 재시작, 일시정지 | 현재 결과 화면과 다시 하기를 사용한다. 타이틀과 일시정지 등 추가 화면 기획은 나중에 검토한다. | 추가 기획 보류 |
| U13 | 미방문 방 시야 | 같은 층의 들어가지 않은 방도 화면에 보이는가? | 일반 방 내부는 플레이어가 직접 처음 들어갈 때 공개한다. 졸개가 먼저 들어가도 공개되지 않는다. 방문한 방은 해당 판 동안 공개되며 다시 하기에서는 방문 기록을 초기화한다. | 결정 |
| U14 | 지나간 방 기억 | 졸개가 지나가며 본 방도 기억하는가? | 배정받아 들어간 방만 기억한다. | 결정 |
| U15 | 같은 틱 처리 순서 | 작업 완료, 제안 만료, 마감이 같은 프레임에 일어날 때 순서 | 남은 시간까지만 진행하고, 작업 완료 → 제안 만료 → 마감 순으로 처리한다. | 결정 |
| U16 | 헬하운드 예외 명령 | 배출하러 나가 있을 때, 배출 구역이 비어 있을 때 명령하면? | 명령을 거절하고 배출 중과 적치물 없음 각각의 사유를 안내한다. 둘 다 해당하면 배출 중을 먼저 알린다. | 결정 |
| U17 | 아트·연출 | 참고 게임, 최종 아트 방향, 마왕 등장 연출 | 현재 연결된 아트와 마왕 등장 연출을 사용한다. 추가 연출과 최종 아트 방향은 나중에 정한다. | 추가 기획 보류 |
| U18 | 해상도 | 기준 해상도 | 가로 1920×1080. HUD의 기준 해상도와 Windows 플레이어의 기본 화면 크기에 적용한다. | 결정 |
| U19 | 밸런스 값 | §11의 생성 예산, 속도·시간, 순찰 경로, 계단 시간, API 대기 한도, 통보 표시 시간 | 현재 설정으로 플레이하고 결과를 보며 수치를 조정한다. 생성·작업자 수치는 `Spec/ContaminationSpawn.md`와 설정 에셋을, 계단은 `ViewSettingsSO`의 2초를 출발점으로 삼는다. | 플레이테스트로 조정 |
| U20 | 플레이어 운반 감속 | GDD §4 "무거운 잔해를 운반하는 동안 이동 속도가 크게 감소"의 정도 | **결정**: 무거운 잔해 운반 중 기본 속도의 50%. 배율 값은 WorkerStatsSO(A), 결과 속도는 `IMatchReadModel.PlayerMoveSpeed` | 결정 |
