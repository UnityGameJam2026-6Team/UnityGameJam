# 마왕 도착 전 시설 청소
## 게임플레이 및 구현 명세

**문서 버전** 0.2 · **갱신일** 2026-11-18  
**플레이 시간** 180초 · **판정 구역** 9개 · **졸개** 5종 각 1마리

## 1. 게임 목표와 코어 루프

마왕이 도착하기 전 3분 동안 플레이어와 졸개가 시설을 청소한다. 성공하려면 일반 방 6개와 층별 로비 3개가 **각각 60% 이상**, 시설 전체가 **85% 이상**이어야 한다.

플레이어가 반복하는 판단은 **어느 구역에 어떤 졸개를 보내고, 졸개가 작업하는 동안 자신은 어디에 시간을 쓸지**다. 여러 방에 분업할 수도 있고, 오염 유형이 섞인 방에 서로 다른 졸개를 보내 각각의 작업을 처리하게 할 수도 있다.

1. 1층 로비에서 대기 중인 졸개에게 말해 담당 방을 지정한다. 방 이름과 층수는 보이므로 직접 확인하지 않은 방에도 배정할 수 있다.
2. 졸개는 이동부터 청소까지 수행한다. 플레이어는 다른 방을 둘러보거나, 청소에 합류하거나, 1층에서 헬하운드에게 배출을 명령한다.
3. 졸개에게 수행할 일이 남지 않으면 다음 방 이동을 제안한다. 플레이어는 제안을 승인하거나 보류하고, 작업 중이거나 복귀 중인 졸개에게는 직접 말을 걸어 새 방을 맡길 수 있다.
4. 180초가 지나면 마왕이 등장한다. 운반 중인 폐기물을 현재 위치에 모두 내려놓은 뒤 최종 청결도를 계산한다.

## 2. 시설 구조와 평면도

평면도상 위·아래·좌·우를 기준으로 위치를 표기한다. 층마다 로비와 해당 층 복도를 하나의 판정 구역으로 묶는다. 로비는 층별로 각각 점수를 낸다.

| 층 | 일반 방 | 로비·화장실 및 주요 위치 |
| --- | --- | --- |
| 1층 | **다목적실**은 위쪽 큰 방, **휴게실**은 왼쪽 아래, **창고**는 오른쪽 곡선 방 | 왼쪽 아래에 화장실, 중앙 로비에 플레이어 시작점(스케치의 붉은 표시). 아래 가운데 현관에 헬하운드 대기점과 별도의 폐기물 배출 구역이 있다. |
| 2층 | **회의실**은 왼쪽 아래, **작업실**은 오른쪽 아래 | 회의실 위쪽에 화장실. 중앙 공간과 복도는 2층 로비에 속한다. |
| 3층 | **간부실**은 위쪽 큰 곡선 방 | 아래쪽에 3층 로비와 화장실이 있다. |

- 층간 이동은 계단으로 한다. 플레이어와 졸개가 층을 바꿀 때 이동 시간이 든다.
- 화장실은 각 층에 1개, 각 화장실의 물걸레는 2개다. 화장실 자체에는 청결도 판정을 적용하지 않는다.
- 플레이어와 일반 졸개는 1층 로비에서 시작한다. 헬하운드는 1층 현관에서 대기한다.
- 카메라는 플레이어를 중심으로 이동하는 내려다보는 구도이며, 플레이어가 현재 있는 층만 표시한다.
- 배정 화면에서는 방 이름과 층수를 확인할 수 있다. 구역의 현재 청결도, 최저치, 기준 미달 여부는 해당 구역에 직접 들어가 HUD에서 확인한다. 졸개가 먼저 방문하거나 청소해도 플레이어에게 구역 수치가 공개되지 않는다.

## 3. 오염 생성과 청소

### 3.1 오염 유형과 가중치

| 유형 | 가중치 | 처리 방식 |
| --- | ---: | --- |
| 무거운 잔해 | 4 | 부서진 잔해 등 폐기물. 1층 현관 배출 구역까지 운반하거나 슬라임이 먹어 처리한다. |
| 일반 쓰레기 | 3 | 1층 현관 배출 구역까지 운반하거나 슬라임이 먹어 처리한다. |
| 어질러진 작은 물건 | 2 | 지정된 자리에 가져다 놓는다. |
| 바닥 얼룩 | 1 | 물걸레를 가져와 얼룩별로 닦는다. 플레이어는 한 번 상호작용한 뒤 일정 시간 작업한다. |

- 오염의 종류, 개수, 위치는 판마다 바뀐다. 방마다 생성 비율이 다르며, 시설 전체의 시작 오염량은 판마다 비슷하게 맞춘다.
- 판을 시작할 때 각 판정 구역에 오염이 최소 1개 있다. 진행 중 새 오염은 생성하지 않는다. 기존 폐기물을 다른 구역에 내려놓으면 그 구역의 오염으로 옮겨 붙는다.
- 오염 개체 하나가 작업 하나다. 플레이어와 졸개가 같은 방에서 서로 다른 개체를 병행 처리할 수 있다. 한 개체는 한 작업자가 선점한다. 대상이 사라지거나 다른 작업자가 먼저 잡으면 다른 대상을 찾는다.
- 진행 중 재배정해도 완료된 작업은 유지된다. 이미 운반 중인 물건은 그 자리에 내려놓고 새 방으로 이동한다.

## 4. 플레이어와 졸개의 능력

| 인원 | 역할 및 수행 제한 |
| --- | --- |
| 플레이어 | 모든 직접 청소 작업과 졸개 지휘를 수행한다. 무거운 잔해를 운반하는 동안 이동 속도가 크게 감소한다. |
| 고블린 | 가벼운 물건을 빠르게 옮긴다. 일반 쓰레기를 1층 현관까지 운반할 수 있다. 무거운 잔해 운반은 작업 후보에서 제외한다. |
| 오크 | 무거운 잔해를 1층 현관까지 운반할 수 있는 일반 졸개다. 가벼운 물건과 일반 쓰레기도 운반한다. |
| 스켈레톤 | 도구 사용과 물걸레질에 능숙하다. 물건과 폐기물을 운반하는 청소 작업은 할 수 없다. 작업에 필요한 물걸레는 직접 가져온다. |
| 슬라임 | 일반 쓰레기와 무거운 잔해를 먹어 처리한다. 운반과 도구 사용은 할 수 없다. 횟수 제한은 없으며 한 건의 소화가 끝나야 다음 작업을 할 수 있다. 소화 중에는 이동할 수 있다. |
| 헬하운드 | 일반 방 청소 배정에서 제외한다. 플레이어의 현관 대면 명령으로 배출 구역에 적치된 폐기물을 처리한다. |

고블린과 오크는 일반 작업도 수행한다는 규칙을 적용한다. 스켈레톤의 운반 제한과 슬라임의 운반·도구 사용 제한이 우선한다. 종별 이동 능력, 구체적인 속도와 행동 시간은 밸런스 값이다.

## 5. 일반 졸개 행동 규칙

### 5.1 방 배정 및 자동 작업

1. 플레이어가 졸개에게 직접 말을 걸어 방을 지정한다. 방을 고르는 동안 해당 졸개는 멈춘다. 시설 타이머는 계속 흐른다.
2. 졸개는 배정 방으로 이동한다. 도착하면 눈앞에 보이는 작업부터 확인하고, 대상이 없으면 정해진 동선을 한 바퀴 돈다. 방이 정리됐을 가능성이 있어도 현장에서 확인한다.
3. 각 졸개는 **작은 물건 정리 → 폐기물 처리 → 물걸레질** 순서를 따른다. 폐기물 중에서는 **무거운 잔해 → 일반 쓰레기** 순서로 본다. 같은 유형에 후보가 여럿이면 가까운 것부터 고른다. 해당 졸개가 수행할 수 없거나 다른 작업자가 선점한 개체는 건너뛴다.
4. 배정이 유지되는 동안 같은 방을 맡는다. 폐기물을 들고 1층 현관에 적치한 졸개는 원래 방으로 돌아가 작업을 반복한다. 이동 경로에 있는 다른 방의 오염은 별도 지시 없이 처리하지 않는다.
5. 맡은 방에 더 이상 수행 가능한 일이 없으면 다음 방을 제안한다. 오크만 처리할 수 있는 잔해가 남았거나 다른 졸개가 마지막 작업을 잡았다면, 고블린은 대기하지 않고 다음 방을 제안할 수 있다.
6. 작업·이동·로비 복귀 중인 졸개에게 직접 말을 걸어 새 방을 맡길 수 있다. 새 방이 확정되면 즉시 목적지를 바꾸고, 이전에 운반 중이던 물건은 그 자리에 내려놓는다.

### 5.2 상태 전이

| 현재 상태 | 사건 | 다음 상태 |
| --- | --- | --- |
| 1층 로비 대기 | 대면 배정 | 지정 방으로 이동 |
| 지정 방으로 이동 | 도착 | 현장 확인·탐색·작업 |
| 현장 확인·탐색·작업 | 수행할 일 발견 | 담당 개체 작업 후 같은 방에서 다음 작업 선택 |
| 현장 확인·탐색·작업 | 수행할 일 없음, 이동 후보 있음 | 이동 제안 생성 및 응답 대기 |
| 현장 확인·탐색·작업 | 수행할 일 없음, 이동 후보 없음 | 응답 불필요 통보 후 1층 로비 복귀 |
| 이동 제안 대기 | 승인 | 제안한 방으로 이동해 현장 확인 |
| 이동 제안 대기 | 보류 또는 만료 | 1층 로비 복귀 |
| 1층 로비 복귀 | 도착 | 대기. 다시 대면 지시를 받기 전까지 새 제안을 올리지 않음. |
| 작업·이동·복귀 중 | 대면 대화 후 새 방 확정 | 현재 행동을 정리하고 새 방으로 즉시 이동 |

## 6. 이동 제안과 API 대사

- 졸개는 **직접 관찰한 현재 방**, **이전에 직접 본 방 상태**, **다른 졸개가 어디서 일하는지**를 안다. 이전에 본 방의 상태는 다른 작업자가 청소해도 자동 갱신되지 않는다. 다른 졸개의 작업 위치를 안다고 해서 그 구역의 현재 오염까지 아는 것은 아니다.
- 근처 방, 다른 졸개가 일하는 방, 이전 기억으로 작업이 있을 만한 방을 제안할 수 있다. 미확인 방은 **탐색**을 제안한다. 걸레가 모두 사용 중일 때도 다른 방을 탐색하겠다고 제안할 수 있다.
- API는 해당 졸개의 인지 범위와 종별 말투를 바탕으로 다음 목적지와 대사를 제안한다. 관찰하지 않은 완료 사실이나 오염 유형을 단정하지 않는다.
  - 직접 관찰한 작업의 경우 “오크가 마지막 잔해를 들었어. 난 여기서 할 일이 없는데, 창고로 갈까?”
  - 위치만 확인한 경우 “오크가 회의실에 있어. 나도 가볼까?”
  - 도구가 없는 경우 “물걸레가 전부 사용 중이야. 다목적실부터 둘러볼까?”
- API가 늦거나 실패하면 기본 대사로 이동을 제안한다. 제안할 곳이 없으면 응답 불필요 메시지로 알리고 1층 로비에 복귀한다.
- **승인/보류 제안은 표시된 순간부터 7초**다. 졸개는 응답을 기다리는 동안 멈춘다. 새 메시지는 우측 하단에서 올라오며 기존 메시지를 위로 민다. 플레이어는 응답이 필요한 제안부터 도착 순서대로 입력한다. 뒤에 있는 제안도 표시 시점부터 시간이 흐른다.
- 복귀 통보는 승인 슬롯을 차지하지 않는다. 통보가 화면에 남아 있어도 다른 졸개의 승인·보류를 입력할 수 있다.
- 승인된 목적지가 이미 청소됐어도 일단 간다. 도착해 확인하고, 할 일이 없으면 탐색·배회한 뒤 다시 제안하거나 복귀를 통보한다.
- **구현안.** 요청·응답에 졸개 ID와 배정 ID를 연결한다. 재배정이나 판 종료 이후 도착한 응답과 유효하지 않은 목적지는 적용하지 않는다. 기본 대사와 같은 시점에 API 응답이 도착해도 제안은 한 건만 표시한다.

## 7. 도구와 폐기물 상세

### 7.1 물걸레 대여·사용·반납

1. 닦을 얼룩이 있으면 화장실에서 물걸레를 가져온다. 해당 층의 물걸레가 모두 사용 중이면 다른 층 화장실로 간다.
2. 전체 6개가 모두 사용 중이면 기다리는 대신 다른 방 또는 작업을 제안한다. 알려진 상황을 바탕으로 탐색 후보가 없으면 통보 후 로비에 복귀한다.
3. 걸레는 여러 얼룩에 계속 사용할 수 있다. 걸레를 든 상태로 물건이나 폐기물을 들 수 없다.
4. 물걸레를 가져가는 동안 다른 작업자가 마지막 얼룩을 닦았으면, 걸레를 가져간 다음 배정 방에서 직접 확인한다. 작업이 안 보이면 탐색·배회한 뒤 보고한다.
5. 작업을 마치면 걸레를 빌린 화장실에 반납한다. 걸레를 쥔 상태에서 새 방을 지시받을 때의 정확한 반납 순서는 구현 시 확정한다.

### 7.2 운반과 1층 현관 배출

| 폐기물 상태 | 점수 적용 |
| --- | --- |
| 방이나 로비 바닥에 놓여 있음 | 현재 놓인 구역과 시설 전체 오염에 포함 |
| 플레이어 또는 졸개가 운반 중 | 운반 중에는 구역과 시설 전체 오염 집계에서 제외 |
| 이동 중 바닥에 내려놓음 | 내려놓은 구역과 시설 전체 오염에 다시 포함 |
| 1층 현관 배출 구역에 적치 | 1층 로비 및 시설 전체 오염에 포함 |
| 헬하운드가 배출하러 출발 | 출발 시점에 포함된 배출 묶음을 오염 집계에서 제거 |
| 슬라임이 먹어 소화 중 | 구역 및 시설 오염 집계에서 제외. 마왕이 등장해도 바닥에 내려놓지 않음. |
| 슬라임 소화 완료 | 개체 처리 완료. 졸개는 다음 작업 수행 가능. 오염 점수를 중복해서 차감하지 않음. |

- 한 작업자가 한 번에 들 수 있는 폐기물은 1개다. 2·3층 로비나 1층 로비 일반 바닥에 둔 폐기물은 현관의 지정 구역까지 다시 운반해야 한다.
- 플레이어가 헬하운드에게 직접 말을 걸면, 헬하운드는 현관 구역의 일반 쓰레기와 무거운 잔해를 함께 가져간다. 양과 무관하게 배출 이동 시간은 같다.
- 출발 전에 쌓인 폐기물만 이번 묶음에 포함한다. 출발 후 새로 적치된 폐기물은 다음 배출 몫이다. 헬하운드는 배출 후 현관에 돌아와 대기한다.
- 슬라임은 소화 중에도 이동하고 새 방에 도착할 수 있다. 그동안 추가로 먹거나 다른 작업을 하지는 못한다. 새 방에 먼저 도착하면 소화 종료 후 작업을 시작한다.

## 8. 청결도 및 마왕 도착 시 처리

### 8.1 계산

| 범위 | 기준 | 성공 조건 |
| --- | --- | --- |
| 개별 구역 | 해당 판 시작 시 해당 구역에 존재한 가중 오염 합계 | 일반 방 6개와 층별 로비 3개가 각각 60% 이상 |
| 시설 전체 | 해당 판 시작 시 시설 전체에 존재한 가중 오염 합계 | 시설 전체 85% 이상 |

계산은 **청결도 = 100 × (1 − 현재 오염량 ÷ 시작 오염량)**을 0~100% 범위에 제한하는 방식으로 명시한다. 현재 오염량은 포함 상태인 개체의 가중치 합이다. 예를 들어 시작 오염량이 10인 1층 로비가 다른 층 폐기물을 받아 오염량 15가 되면 청결도는 0%로 표시된다. 시설 점수는 방별 퍼센트의 평균이 아닌 시설에 포함된 가중 오염 총량으로 계산한다.

### 8.2 마감 순서

1. 180초에 마왕이 등장한다.
2. 플레이어와 졸개가 운반 중인 **폐기물**을 현재 위치에 강제로 내려놓는다. 내려놓은 장소를 기준으로 오염을 다시 귀속한다.
3. 제자리에 돌려놓기 전인 **작은 물건**은 오염으로 남는다. 마감 때 별도로 내려놓는 연출은 보류한다.
4. **슬라임이 소화 중인 폐기물**은 집계에서 제외한다. 헬하운드가 이미 배출하러 출발한 묶음도 집계에서 제외한다. 현관에 남아 있는 폐기물은 1층 로비에 포함한다.
5. 청결도를 다시 계산한다. **9개 구역 기준과 시설 전체 기준을 모두 만족하면 성공**, 한 기준이라도 미달하면 실패한다.

**판정 예시.** 시설 전체가 90%여도 3층 로비가 59%이면 실패한다. 마감 전에 현관의 폐기물을 헬하운드가 가져가면 바로 점수에 반영된다. 현관에 도착하기 전인 오크가 들고 있던 잔해는 마왕 등장과 함께 내려놓으므로 최종 오염량에 다시 포함된다.

## 9. HUD 및 입력

| 위치 | 노출 정보 |
| --- | --- |
| 상단 중앙 첫 줄 | 마왕 도착까지 남은 시간. 시간·분·초 두 자리씩 표시. |
| 상단 중앙 둘째 줄 | 시설 전체 청결도. **85% 미만**이면 기준 미달 표시. |
| 좌측 상단 | 첫 줄에 현재 층·장소, 둘째 줄에 현재 지역 진척도(구역 청결도와 기준값). 해당 구역 **60% 미만**이면 기준 미달 표시. |
| 좌측 하단 | 접을 수 있는 졸개 현황 패널. 담당 방과 현재 행동 확인. |
| 우측 하단 | 졸개와 상호작용하면 방 선택 패널을 연다. 이동 제안과 복귀 통보는 선택 버튼을 가리지 않게 배치한다. 제안에는 승인/보류 및 7초 응답 상태 표시. |

원격 안내에는 방 이름과 층수를 사용한다. 다른 방의 실시간 점수와 미달 표시를 원격으로 노출하지 않는다. 졸개 현황 패널에는 졸개 상태를, 우측 메시지에는 응답할 제안을 표시해 같은 정보를 여러 곳에 반복하지 않는다.

## 10. 구현 확인 시나리오

| 확인 항목 | 통과 조건 |
| --- | --- |
| 미확인 방 배정 | 방 이름과 층수로 배정 가능. 졸개는 현장 작업을 시작하고, 방 청결도는 플레이어가 직접 입장할 때 표시된다. |
| 같은 방 분업 | 고블린과 오크가 별개 개체를 맡는다. 무거운 잔해만 남으면 고블린은 이동을 제안할 수 있다. |
| 재배정 | 무거운 잔해 운반 중인 오크에게 말을 걸면 선택 중 정지한다. 확정 시 잔해를 내려놓고 새 방으로 간다. 복귀 중에도 재배정할 수 있다. |
| 오염 이동 | 작업실에서 든 잔해는 이동 중 집계에서 빠지고, 2층 로비에 내려놓으면 2층 로비 오염으로 잡힌다. |
| 배출 경계 | 1층 로비 일반 바닥 폐기물은 배출되지 않는다. 현관 지정 구역에 출발 전에 적치한 묶음만 제거된다. |
| 소화 중 재배정 | 슬라임이 새 방까지 이동할 수 있다. 소화를 끝내기 전에는 새 작업을 시작하지 않는다. 마감 시 소화 중 오염은 포함하지 않는다. |
| 걸레 소진 | 해당 층이 비면 다른 층으로 이동한다. 여섯 개가 모두 사용 중이면 다음 작업이나 탐색을 제안한다. |
| 제안 대기열 | 모든 메시지가 표시 시점부터 독립적으로 7초를 센다. 승인·보류는 가장 오래된 활성 제안부터 입력하고 통보는 입력을 막지 않는다. |
| 오래된 방 정보 | 졸개가 과거 관찰에 근거해 승인받고 이동한다. 도착 시 직접 확인하고, 작업이 없으면 탐색 후 다시 제안하거나 복귀한다. |
| 마감 동시 처리 | 운반 중 폐기물을 바닥에 다시 등록한 후 계산한다. 시설 85%와 각 구역 60%를 함께 검사한다. |

첫 플레이테스트에서는 시설의 시작 가중치를 일정 범위로 맞추고, 3분 동안 **각 구역 60%와 시설 85%를 함께 달성할 수 있는지**, **분업과 집중 배치 중 어느 쪽이 유리한지가 방 구성에 따라 바뀌는지**, **1층 현관을 들르는 타이밍이 실제 선택을 만드는지** 확인한다.
